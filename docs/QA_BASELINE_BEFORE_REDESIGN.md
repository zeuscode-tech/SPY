# SPY 2.0 — неполный baseline QA (до редизайна)

Дата фиксации: 25 ноября 2026. Источник результатов: сообщение владельца проекта о проверке приложения. Это **не** полный протокол независимого QA и не подтверждение всех сценариев.

## Подтверждено в переданных результатах

- Приложение собирается и запускается.
- Основные настройки работают и сохраняются.
- Пользовательские слова и имена игроков работают.
- Партия запускается, секретная роль отображается.
- Есть реальное использование приложения игроками без массовых сообщений о проблемах (качественное наблюдение, не измеренная статистика).

## Не проверено / доказательств недостаточно

- Все сочетания количества игроков, числа шпионов и двух режимов игры.
- Полнота выбора категорий, включая отдельные наборы Anime/Movies.
- Корректность роли каждого игрока, отсутствие подсматривания.
- Мультитач при выборе начинающего.
- Таймер при background/foreground, пауза и окончание партии.
- Полноценная Android release AAB-сборка и подпись, обновление опубликованного приложения.
- Offline, Android Back на каждом экране, малые экраны, доступность, логи Android.
- Скорость, утечки памяти, длительные сессии.
- Монетизация: пока не реализована.

## Скриншоты

В рамках этой записи файлы скриншотов не предоставлены, поэтому в репозиторий ничего не прикреплено. Если есть локальные снимки предыдущего QA, приложить их к этому baseline отдельно. Не выдавать отсутствие скриншотов за подтверждённые тесты.

## План тестирования

1. Во время редизайна: проверять TypeScript, целостность данных и сборку Capacitor автоматическими проверками.
2. После обновления основных экранов: короткий Android smoke-test (настройка → категории → роль → таймер → результат → новая игра).
3. Перед Google Play: полный release QA, включая известные QA-001 и QA-002, offline и фоновые состояния.

**Решение:** остановить подробное exploratory QA на данном этапе; приоритет — редизайн главного экрана и поддержка существующих функций.
